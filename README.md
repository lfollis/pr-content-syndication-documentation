# PR Content Syndication Checker

A Python-based tool used to measure content syndication and media pickup of press releases by searching for article placements and social shares across the web.

## Features

- Automated Bing search discovery
- Press release syndication detection
- Social share identification
- Headline matching
- Excel report generation
- URL categorization
- Duplicate removal

## Use Cases

- Public Relations Reporting
- Earned Media Tracking
- Content Syndication Analysis
- Press Release Pickup Monitoring

## Example Workflow

1. Enter a headline
2. Run the script
3. Search results are collected
4. Matching articles are identified
5. Results are exported to Excel

## Technologies

- Python
- Requests
- BeautifulSoup
- Pandas
- Fake User Agent
